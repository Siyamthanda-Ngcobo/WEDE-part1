# WEDE-part1
Kagiso Youth Development Trust — Simple Design
Preview

What this is
A 5-page visual preview of the Kagiso Youth Development Trust website, styled with basic
CSS only (solid colours, borders, simple box layout — no CSS Grid, no gradients, no
rounded circles). This is meant as a design reference for Part 2 (CSS styling), not a
replacement for the plain-HTML Part 1 submission files.

Pages

File Purpose
index.html Homepage — hero, intro, programme highlights
about.html History, mission, vision, team
services.html Full programme details (Mentorship, Digital Literacy, Business Skills)
enquiry.html Enquiry form for participants, volunteers, and sponsors
contact.html Address, contact details, and a short contact form

Design reference
Colours: deep orange #E8622C , charcoal #2E2E2E , off-white #FAF7F2
Typography: Arial/sans-serif throughout (kept simple — swap in Poppins/Open Sans
once Google Fonts is added)
Navigation: a dark bar below the header, with the current page highlighted ( .active
class)
Call to action: .btn class — solid background, bold border, larger padding so it stands
out

How to use
Open any .html file directly in a browser to preview it — all pages link to each other via the
navigation menu, so you can click through the whole site. Copy the <style> block into

Thuli’s Home Bakery — Simple Design Preview

What this is
A 5-page visual preview of the Thuli’s Home Bakery website, styled with basic CSS only
(solid colours, borders, simple box layout — no CSS Grid, no gradients, no rounded circles).

This is meant as a design reference for Part 2 (CSS styling), not a replacement for the plain-
HTML Part 1 submission files.

Pages
File Purpose
index.html Homepage — hero, intro, product highlights
about.html Business story, mission, vision, baker profile
products.html Full product list with indicative pricing
enquiry.html Order enquiry form
contact.html Address, contact details, and a short contact form

Design reference
Colours: blush pink #F4C7C3 , cream #FFF8F0 , deep brown #5C3A21
Typography: Georgia/serif for headings, Arial/sans-serif for body text and forms (swap
in Playfair Display/Lato once Google Fonts is added)
Navigation: a dark brown bar below the header, with the current page highlighted
( .active class)
Call to action: .btn class — solid background, bold border, larger padding so it stands
out
